# index-request (1st and 15th, 7:40 am Central, Todd's PC, after question-pages; was Fridays, cut by Todd, Nov 6, 2026)

One job: ask Google to index the live proofnotfluff.com pages it has not indexed yet, and read the Friday Search Console numbers the cloud question-pages run cannot reach. Runs in the built-in browser on Todd's PC (scheduled task "PNF site: index request", requires the computer). Todd's go, Oct 23, 2026, 7:11 pm. coo/CONSTITUTION.md binds this run. You never sign in, accept terms, change a Search Console setting, remove a URL, or edit a page; you inspect, request indexing, read reports, and log. Hand-off (Todd's go in a live chat, Nov 6, 2026: "ok let's go with one"): a task that requires the computer cannot attach a GitHub repo, so its push always failed with 403. The clone is read only and a push is never tried; results go to the scoreboard hand-off record in step 7, and the daily cloud question-pages run commits them (tools/apply_handoff.py).

## Inputs (Reads)
- `python3 tools/indexnow_submit.py --all --dry-run`: the live list (docs/sitemap.xml minus noindex pages). Nothing else counts as live.
- seo/index-requests.json: {url: last day requested}. seo/QUESTIONS.md: the live question pages. seo/RESULTS.md: past lines.
- Search Console, URL property https://proofnotfluff.com/, signed in as proofnotfluff@gmail.com in the built-in browser.

## Process (Executes)
1. Date from bash. `python3 tools/check_repo.py --preflight index-request`. git pull (read only: never commit or push from this run).
2. Load the built-in-browser skill. Open Search Console. Not signed in, or the browser can't be reached: write the step 7 line as "not run" with the reason, tell Todd in one line, stop.
3. Order the live list newest first: URLs added to docs/sitemap.xml since the last index-request line, then the rest in reverse sitemap order (site/pages.json appends new pages last).
4. For each URL: the top search box, URL Inspection, wait for the result. "URL is on Google" counts as indexed. Otherwise, unless seo/index-requests.json shows it requested in the last 7 days (a repeat request changes nothing), click Request indexing and wait for the dialog: "Indexing requested" counts as requested (today goes in the record's index_requests, step 7); "Quota Exceeded" or any error counts as refused with its reason. After the first Quota Exceeded, request nothing more today and keep inspecting. Close every dialog with its Dismiss button before the next URL, never by pressing Return.
5. Friday Search Console lines (question-pages step 7 points here): Performance, Search results, last 28 days, Pages filter, one line per live question page for the record's results_lines (step 7): page, impressions, clicks, average position, date. First Friday of a month, list pages at average position 8 to 20 as refresh candidates (a refresh is a run of its own).
5b. Every Friday, for the weekly traffic report (Todd's go, Oct 26, 2026): Performance, Search results, last 7 days, Pages tab, every page with an impression: the record's search_console object, the seo/search-console.json shape {"date": today, "window": "7 days", "pages": {slug: {"impressions", "clicks", "position"}}}, slug = the page path without slashes ("home" for /). Counts only; no queries. tools/traffic_report.py attaches it to the Monday report.
6. Read numbers from the page text (get_page_text, read_page); screenshots only to read a dialog.
7. The hand-off record, instead of a commit. Scoreboard artifact https://claude.ai/artifact/N9eKZy7Pv39njSe4izVgbE (ArtifactData), collection "handoffs", doc id "index-request-YYYY-MM-DD" (today), set with: run "index-request", date "YYYY-MM-DD", status "pending", results_lines [the run line "- YYYY-MM-DD (index-request): inspected N, already indexed N, requested N, refused N (reason), not requested N (quota or requested in the last 7 days)" first, then the Friday Search Console lines, each starting "- YYYY-MM-DD", no em or en dashes], search_console {the step 5b object, or null}, index_requests {url: "YYYY-MM-DD"} (only URLs requested this run, else {}). Check the record back with a get: every field as written. Never write seo/ or push; question-pages step 1a applies it (tools/apply_handoff.py) and marks it applied.

## Outputs (Writes)
- The scoreboard hand-off record handoffs/index-request-YYYY-MM-DD (status "pending"): the run line and the Friday lines, search_console, index_requests. No repo writes.
- Scoreboard agents/index-request {state, lastRun, lastStatus, lastNote}: counts only.
- A message to Todd only when the run could not start or a count is off (inspected not equal to the live list).
