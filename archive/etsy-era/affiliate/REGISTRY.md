# Affiliate program registry

Owner: the capability scout keeps each row current. When a row's "Read" date is more than 30 days old, it re-reads the program's official page, updates the row and dates it. The COO adds rows. Todd submits every application himself (identity, tax and payout details are his). A row turns "approved" only when Todd says so in chat. Figures are each program's own published terms on the read date, not advice.

**Bona fide user** means the crew really uses the product, so a page may say "we use it" (FTC Endorsement Guides, 16 CFR 255.1(c): an endorser must be a bona fide user). Every other program is described with sourced facts only (legal/README.md section 7).
