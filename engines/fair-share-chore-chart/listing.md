## Description
Founding price for the first 10 buyers, then $8.99.

Split the chores by minutes, not by count. Type up to four names and this workbook splits 42 prefilled household chores so each person does a fair share of the time, re-balances every week, rotates the jobs nobody wants, and prints one chart for everyone.

In the sample home, Cook dinner is 200 minutes a week and Take the bins to the curb is 5. A list that gives each person the same number of jobs can still be lopsided. This one adds up the minutes.

WHAT IT DOES
- Fair Split: each person's fair target, assigned minutes, hours and number of jobs. In the sample couple's week 1, Alex has 469 real minutes and Jordan 478.
- Uneven shares: type 60 and 40 (or any shares) if one person works longer hours. Leave them blank for an even split.
- Weekly Rotation: mark a job "Nobody wants it" and it counts 1.5x (you set the weight) and moves to the next person every week. The rest of the jobs re-balance around it, so every week stays close. In the three-roommate example, each person lands between 313 and 319 real minutes in each of weeks 1 to 4.
- Pin a job to one person ("Always done by") when someone wants it, like cooking.
- Printable Chart: this week's chart for everyone on one page, grouped by person, with a box for each time a job is due.
- Everything recalculates when you change a name, a chore, a minute or a share.
