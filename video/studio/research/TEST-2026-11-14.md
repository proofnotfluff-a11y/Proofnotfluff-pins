# The Nov 14 read: did the Nov 8 studio changes help? (plan set Nov 8, 2026, before any result)

Todd, video-lab chat, Nov 8, 2026: "Set up a fair test that the Nov 14 read can judge, so we know whether the changes
helped." The bars are written here before a single v3 lesson exists. The read changes no gate and no rule on its own.

## Arms
- v3: proven lessons dated 2026-11-26 or later (studio changes 1, 2, 4 and the hook moves run in lint and script).
- base: the 4 proven lessons made before them (angi-four-pros, after-hours-greeting, pay-before-you-leave,
  members-go-first). Same lane, same gates, same team; the only planned difference is the code.
- One table for both: `python3 video/studio/anim.py cohort` (writes research/tests/cohort.json). Rounds count every
  review file a gate wrote (reviews/, its r<n>/ folders, 01_voice/prevoice/), so a rerun forced by another gate counts
  in both arms alike. Platform numbers are the read nearest 72 h after that platform's post (within 24 h).

## Question 1: cost (judged Nov 14, enough data likely: every v3 lesson made by then)
Base (Nov 8): design 2 to 4 rounds (median 3), render critic 2 to 6 (median 3), facts 3 to 4.
- PASS if the v3 median is 2 or fewer for design AND for render critic, with no render-critic fault of the kinds the
  code now catches (text past x 930, a tag over a header, text under the floor, a drawn string facts never saw).
- FAIL if the v3 median for either is 3 or more. Then the next lab run reads the faults and moves the commonest into code.
- Too few: under 2 v3 lessons gated by Nov 14: say "no read", carry to Nov 21.

## Question 2: audience (judged Nov 14 only if 2+ v3 lessons have a 72 h read; otherwise "no read")
Measures per platform at 72 h: views, sends per reach (shares / views), follows. Topic is the biggest thing we know moves
views (our phone cluster), so each lesson is tagged phone or other in the table and compared within its tag when both
arms have one.
- A difference counts only if every v3 lesson beats the base median on the same platform, on views or on sends per
  reach. With 2 to 4 lessons an arm, anything less is noise and is reported as "no difference shown", not as a loss.
- What this cannot show: whether a gain came from the hook moves, the kit or the topic picked. It is one bundle.
